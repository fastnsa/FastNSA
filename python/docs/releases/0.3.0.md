# FastNSA 0.3.0

FastNSA provides native-accelerated network spatial analysis for Python.

## Highlights

- Point-to-network matching with reusable mapped event inputs.
- Network kernel density estimation with ADA/LION and optional event weights.
- Network K-function and spatiotemporal network K-function methods.
- Reproducible Monte Carlo analysis, result persistence, and optional
  pandas/xarray integration.
- A lightweight NumPy runtime backed by the native C API, with geospatial
  integrations available as optional extras.
- Progress reporting, cooperative cancellation, and native safety regression
  coverage.

## Compatibility

- Python 3.11 or newer; the release test matrix covers Python 3.11 and 3.12.
- Base runtime dependency: NumPy; baseline installation tests use NumPy 1.26.4.
- Wheels target Linux x86_64 (manylinux2014), Windows AMD64, macOS x86_64, and
  macOS arm64. A source distribution is also provided.
- Native ABI remains version 2.
- Python 3.9/3.10 are not supported by this release. Older FastNSA 0.2.0
  distributions are not the runtime for this release.

## Installation

```bash
python -m pip install --upgrade --only-binary=:all: fastnsa==0.3.0
python -m fastnsa._selftest
```

See the documentation for optional `geo`, `osm`, `dataframe`, `xarray`,
and `viz` integrations. Source builds require CMake and a C++17 compiler.

This is the Python/native package release. QGIS plugin packages have their own
version and acceptance process.
